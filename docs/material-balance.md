# 材料需求與掉落配比

v13.3 起，探索掉落的零件與布料會依「需求量」調整同一階內的出現比例（同類別、同階互比）。

## 規則
- **需求**：所有設施、防禦建築、研究（每一級，最高 15 級）與裝備製作（每種型號一次）需要的零件與布料總和。
- **調整**：同類別、同階的材料，掉落權重乘上「佔需求的比例 ÷ 原本佔掉落的比例」。
  - 倍率限制在 ×0.6～×2，並保持該階的總掉落量不變。
  - 子彈、藥品製作與圍牆修繕會反覆用到的材料（消耗品材料）不會被降低，倍率至少 ×1。
- **自動更新**：遊戲依目前的設定即時計算（`src/systems/MaterialBalance.js`）。之後新增或修改研究、建築、裝備、子彈或藥品配方，配比會自動跟著調整，不需要手動改數字。
- **參考此表的系統**（之後新增跟材料有關的系統也要參考此表）：
  - 探索掉落：同階內的出現比例（`LootStock.pickSupply`）。
  - 黑市交換：每種材料的價值點數＝每階基準（1、3、6、13）× 稀缺度（限制 ×0.5～×3）；同價值 5 換 1，低一階換高一階再 ×2。
  - 黑市售價與回收價：零件與布料依稀缺度調整（×0.7～×1.5）。
  - 黑市上架：比較缺的零件與布料比較常上架。
  - 稀缺度＝同階內「佔需求的比例 ÷ 調整後佔掉落的比例」。
- **更新紀錄**：改動成本或配方後，執行 `npm run balance -- --md` 重新產生下方報表，連同改動一起提交。
