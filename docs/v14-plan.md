# v14 新地圖與控制點規劃（已確認事項）

全部完成後以 v14.0.0 一起發版；分 3 批實作。

## 地圖區域
- 由西到東：安全（玩家據點區）→ 一般 → 警戒 → 危險 → 致死 → 深淵（中間最寬）→ 致死 → 危險 → 警戒 → 一般 → 安全（三大勢力大本營）。交界不規則。
- 左側安全區、一般區：沒有控制點，可自由探索；避難所只能建在左側安全區。
- 右側一般區、安全區：三大勢力大本營領地（赤月上、黑曜中、冥府下），不能攻打、不能探索；本陣不出兵。
- 地下城位置與機制不變。重度感染據點移除。

## 建築規模（各區比例：小／中／大／巨）
安全 55/40/5/0、一般 45/45/10/0、警戒 35/50/15/0、危險 25/50/25/0、致死 15/35/35/15、深淵 5/25/40/30。
藥局、麵包店一律小型；軍事基地一律巨型；樹林最多中型。整體資源比例維持（食物 26、木材 18、燃料 7、零件布料 18、藥品 13、裝備彈藥 18）。

## 控制點（21 個，範圍不規則，分布於警戒區～深淵區，跨到一般區的部分保留）
- 中立控制點一開始由感染者守軍佔據；佔領後該區只有佔領者與其好友可探索。
- 每天 06:00 收益：由控制點出發的運輸隊走回避難所後入庫（不佔用駐防人員，沒有駐防也有收益）。
- 收益對象：佔領者與駐守者（佔領者的好友在此駐防）都可以拿；同一人既是佔領者又是駐守者時只給一份。
- 駐防：佔領者與佔領者的好友都可駐防，每名玩家每個控制點最多 2 人。
- 集結打下的控制點為參加者共同擁有；共同擁有者變成敵對時，該控制點回到中立。
- 敵對關係的玩家可以互相攻打控制點。
- 「探索這區」按鈕不做。

## NPC 三大勢力
- 只攻擊與自己範圍相鄰的控制點，最遠到左側警戒區；優先攻擊無人駐守的；勢力之間互相侵犯；打下後留守。
- 勢力可在自己控制點附近建立 NPC 據點（起始 Lv35），數量依擁有的控制點數決定；NPC 據點會出兵攻擊玩家與控制點，本陣不出兵。
- 駐守強度：越靠近前線越強，最強在深淵區；玩家側的致死區比勢力側的致死區弱。

## 圖層與介面
- 原本的危險度圖層按鈕改為切換：危險度 → 勢力圖 → 關閉。
- 勢力圖：淡藍＝自己或好友（可探索）、灰＝其他玩家或中立（不可探索）、三大勢力各一種顏色（不可探索）。
- 玩家資訊視窗的「據點 N 個」改為「控制點 N 個」。

## 改版登入
- 第一次登入顯示新玩法說明；提供一次免費重新選擇避難所（只能選安全區），設施、資源、防禦建築全部保留。
- 設定頁新增「📖 遊戲說明」（新機制＋基本玩法），可重複查看。

## 倖存者上限 12 人
- 最高 12 人；領袖每 3 級 +1（Lv21 達 12 人）；宿舍 Lv9 住滿，Lv10～15 提升居住品質（滿級效果不變）。

## 分批
1. 地圖區域、建築規模、倖存者 12 人、移除重度感染據點、重選避難所、遊戲說明。
2. 控制點：佔領、探索權限、駐防、06:00 運輸收益、集結共同擁有、敵對互攻。
3. 三大勢力：NPC 策略、NPC 據點、勢力圖層、玩家資訊顯示控制點數。
