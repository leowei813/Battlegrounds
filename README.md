# ☣️ 絕地求生 — 真實地圖殭屍放置生存 RPG

在**你所在城市的真實街道**上建立避難所，派遣倖存者搜刮醫院、警局、加油站，研究科技、打造裝備、架設防禦塔，在日夜循環的屍潮中活下去。離線最多累積 24 小時收益。

**技術**：Vite · Phaser 3 · JavaScript (ES Modules) · Leaflet + OpenStreetMap / Overpass API · LocalStorage · 響應式（桌機與手機）

🎮 **線上試玩：<https://leowei813.github.io/Battlegrounds/>**（需輸入通行碼）

目前版本：**v8.52.0**（各版本改動見 [CHANGELOG.md](CHANGELOG.md)）

## 快速開始

```bash
npm install
```

```bash
npm run dev
```

另開一個終端機執行 `npm run server` 啟動帳號／存檔伺服器，再開啟 <http://localhost:5173>，註冊帳號、建立角色即可開始。

## 功能一覽
- 📡 **GPS 偵測**：依手機真實位置偵測 50 公尺內的建築，可看到實際的今日物資
- 🗺️ **真實地圖**：定位或手動座標，OSM 建築自動分類為 9 種地點（住宅、商店、醫院、學校、工廠、加油站、警局、軍事基地、倉庫）
- 🏠 **避難所與前哨站**：避難所一座（8 種設施、可生產），研究後最多 3 座前哨站（只有防禦）；據點依大小可建造 12～20 棟建築，越大越難守；可放棄據點（退還 25%）或搬家
- 🏛️ **文明度**：建築、玩家等級、裝備提升文明度；屍潮強度隨文明度（而非天數）成長，主要據點危險度依文明度 × 係數提升
- ⏳ **放置收益**：6 種資源，離線最多 24 小時
- 🧭 **探索**：5~60 分鐘，物資／倖存者／殭屍／特殊事件／精英怪，可自動探索；每棟建築的物資每天隨機生成，搜刮後清空，每天 00:00 重置
- 🎒 **裝備**：160 種具體型號（近戰 10、各槍種 10 以上、防具各 10 以上、背包 7 種大小），強度 T1～T10 越強越難取得；6 階品級、隨機素質與詞綴；工作台分級製作
- ⚔️ **自動戰鬥**：HP／攻擊／防禦／暴擊／閃避／攻速，職業技能
- 🧟 **殭屍生成**：依區域危險度與日夜刷新，特殊區域有 Boss；夜晚屍潮一波一波來襲
- 🗺️ **區域危險度**：安全區～深淵區 6 級，越危險物資越多、裝備越好，殭屍與屍潮也越強
- 🚗 **載具**：滑板車到巴士共 11 種，影響速度與運載量，會耗油、磨損、可維修
- 🏴‍☠️ **NPC 據點**：會升級、探索、依文明度掠奪玩家，可攻打搶奪資源
- 🛡️ **防禦建築**：路障、陷阱、機槍塔、火焰塔、電磁塔、可駐守的瞭望塔，Phaser 即時屍潮防守
- 👥 **倖存者**：戰士、醫生、工程師、農夫、偵察兵，6 階品級影響成長；廣播招募三選一、每小時固定出現 2 位、品級機率公開；最多 10 人、可驅逐；生命歸零重傷、飢餓扣血、長期重傷飢餓會永久死亡
- 🌗 **日夜系統**：現實 1 小時 = 遊戲 1 天（白天／黃昏／夜晚／午夜）
- 🔬 **研究**：10 分支 78 項科技，每項最高 10 級
- 📜 **任務**：15 章主線、每日任務、17 項成就
- 👤 **帳號與雲端存檔**：註冊帳號後進度只存在雲端，任何事件立即存檔、隨機結果隨存檔固定（無法重讀刷結果），任何裝置登入即讀取最新進度，多裝置即時鎖定防覆蓋（內建伺服器或 Supabase）
- 🎒 **個人背包與倉庫**：每位倖存者有負重與物品格子，倉庫有格子上限，可在避難所存取
- 🌐 **多人互動**：所有玩家的據點與探索隊都會顯示在附近玩家的地圖上；中立／友好／敵對外交、突襲其他玩家、警戒範圍與自動繞路（需雲端後端）

## 指令
| 指令 | 說明 |
|---|---|
| `npm run dev` | 開發伺服器 |
| `npm run build` | 建置到 `dist/` |
| `npm run preview` | 預覽建置結果 |
| `npm run check` | 資料檢查與無頭邏輯模擬 |
| `npm run server` | 雲端存檔伺服器（同時提供 `dist/`） |
| `npm run start` | 建置並啟動伺服器（一鍵正式環境） |
| `npm run test:cloud` | 雲端存檔整合測試 |
